# UX audit (Phase 4, Task 1)

Date: 2026-10-28. Branch: `phase-4-ux`. Audited against `DESIGN_SYSTEM.md` and spec section 7.

## Method and limits

- **Public pages, live (screenshot + measured).** Built-in browser on `https://eypi.cc` at 375x812 and 1280x800, read-only (no form submitted, nothing mutated). Per page: screenshot, then a script measuring interactive elements below 44px (`getBoundingClientRect`), horizontal overflow (`scrollWidth` vs `innerWidth`), heading order, images without `alt`, computed text contrast against the nearest opaque background, and text under 12px. Keyboard focus was checked once (Tab, computed outline).
- **Signed-in pages, static (code), not screenshotted.** Dashboard, links, orgs manage, tix (events, attendees inbox, door mode, builder), my tickets, dp (Frames) campaigns and editor, admin, account were audited by reading `src/views` and `src/components` against `DESIGN_SYSTEM.md`. By owner decision no sign-in was attempted and `npm run dev:local` (production database) was not run. Rows from this group have source `static` and need a screenshot pass before they are treated as confirmed.
- **Pages covered live:** `/`, `/login`, `/privacy`, `/terms` (same `LegalView` as privacy; measured on privacy only), `/orgs`, `/orgs/jpcs`, `/frames/socitfest2026` (the only Frames URL in `sitemap.xml`), `/contact`, a 404 (`/a/b/c`). Desktop (1280) was checked for `/`, `/orgs/jpcs`, `/frames/socitfest2026` only; the others were measured at 375 and are single-column layouts.
- **Not verified:** every signed-in route at both viewports (no screenshots); the public event page `/tix/:slug` (no public event URL exists in the sitemap or on the org profile, and the profile Events tab did not respond to one click, so it was not explored further); `/t/:token`, `/unlock/:slug`, `/expired`, `/report` (need real tokens or slugs, or were not requested); the mobile site-nav sheet (open click not confirmed); a screenshot was refused by the pane twice at 1280 (render timeout) and retried. Screenshots are not saved to the repo (the tool stores them outside the repo; keeping the doc text-only).
- Contrast: no text under 4.5:1 was found on any measured public page.
