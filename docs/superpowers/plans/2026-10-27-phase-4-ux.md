# Phase 4 — UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the real UX problems found by a screenshot audit, then add skeletons, Undo, route transitions, a command palette, better empty states and a PWA install entry.

**Architecture:** Audit first; the owner marks each finding fix/skip/later. Then shared primitives (`Skeleton`, `useUndoToast`, `EmptyState`, `CommandPalette`) are added once and applied across views.

**Tech Stack:** Vue 3, vue-router 4, reka-ui (already installed) for the palette dialog, vue-sonner (already installed) for toasts, View Transitions API.

**Spec:** `docs/superpowers/specs/2026-10-27-eypi-speed-tix-analytics-design.md` §7. Phases 1–3 merged first.

## Global Constraints

- Everything follows `DESIGN_SYSTEM.md`: light only, APC tokens, Plus Jakarta Sans / Syne / JetBrains Mono, no `dark:` utilities, touch targets ≥ 44 px, visible focus.
- Respect `prefers-reduced-motion` for every animation and transition.
- Undo replaces a confirm dialog only when the action is reversible within the undo window (5 s); permanent deletes keep their confirm.
- No pop-up install prompts; install lives in the account menu.
- No new dependencies.
- TDD every task; `npm run typecheck`, `npm test`, `npm run lint` green; owner-style commits, **no co-author or tool trailers**, on `main`.

## Review Focus

- Leaving the page during the 5 s undo window must still commit the action (Task 3 test `commits on pagehide`).
- Command palette must be fully keyboard-usable and trap focus, and `Ctrl+K` must not fire while typing in an input (Task 5 tests).
- View transitions must not run on browsers without the API or under reduced motion (Task 4 test).
- Skeletons must match the final layout height so nothing shifts (Task 2 test asserts fixed heights).
- Empty states must offer exactly one primary action that works for users without an org (Task 6 test).
