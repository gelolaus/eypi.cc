# Phase 1: Nav groups, org gating, mobile bar and profile sheet

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Org-only features disappear for non-members, the rail and menus are grouped as Rams and Orgs, the phone tab bar is Dashboard, Links, My tickets, Wallpaper, Invites, and the profile menu is a bottom sheet on phones.

**Architecture:** `src/config/nav.ts` becomes the only list of destinations, with group, org-only and tab flags. `appNav.ts` filters it by membership and groups it. `AppShell`, `AccountMenu`, `SiteNavSheet` and the command palette render from it. A small shared sheet component gives `AccountMenu` and `OrgSwitcher` one mobile behaviour.

**Tech Stack:** Vue 3, TypeScript, Vitest with happy-dom, lucide-vue-next, Tailwind tokens, the existing `useFocusTrap`.

**Spec:** `docs/superpowers/specs/2026-10-31-nav-groups-dashboard-design.md` (sections "Information architecture" and "Navigation behaviour")

## Global Constraints

- Group ids `rams` and `orgs`; headings render as "Rams" and "Orgs".
- Tab order exactly: Dashboard, Links, My tickets, Wallpaper, Invites. `TAB_COUNT = 5`.
- Rams order: Dashboard, Links, My tickets, Wallpaper, Invites, Orgs. Orgs order: Tix, Frames, Forms, My org.
- Orgs directory is `/orgs`; My org is `/orgs/modify`. `/orgs` must not be active on `/orgs/modify`.
- Membership = `useActiveOrg().orgs.length > 0`. Route guards in `src/router/index.ts` do not change.
- Hint key `localStorage['eypi.hasOrg']` is `'1'` or `'0'`, read and written inside try/catch, cleared on sign-out.
- Tokens only; no `dark:` utilities, no mica, no Geist. Touch targets at least 44px (`min-h-11`).
- Entry bundle budgets stay (JS ≤ 70,000 B, CSS ≤ 22,000 B gzip). Run `npm run release:check` if the repo has it wired, before the last task's commit.
- Commits: Conventional Commits, `type(scope): lowercase imperative subject`, blank line, `- bullet` lines starting with a lowercase verb. Scope `nav` unless noted. No `Co-Authored-By`, `Signed-off-by` or any AI/tool trailer. One commit per task, each green. Tick this task's boxes in this file and include the file in that commit.
- A task is done when its tests pass and `npm run typecheck` passes. Run single files with `npx vitest run <file>`.

## Review Focus

1. A user who just lost their last org membership (list refetch returns `[]`) must see the Orgs section vanish and the hint flip to `'0'` (Task 3).
2. A slow `/api/orgs` response must not flash the Orgs section for a non-member (hint `'0'` or absent) nor hide it for a known member (hint `'1'`) (Task 3, Task 4).
3. `/orgs/modify/xyz` highlights My org only; `/orgs` and `/orgs/some-slug` highlight Orgs only (Task 1).
4. 360px-wide tab labels ("My tickets", "Wallpaper", "Invites") do not wrap or overlap badges (Task 4).
5. Admin users keep Admin and Account in the menu, and an admin with no org still sees no Orgs section (Tasks 2 and 5).
