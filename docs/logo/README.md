# Eypi mascot

Eypi is the eypi.cc mascot: a baby ram, the APC spirit animal.

- `eypi-icon-source.png`: the 1254 px source image (generated with GPT Image from `ram-prompts.md`, candidate chosen by the owner).
- `ram-prompts.md`: the six prompts used for the candidate batch.
- `public/`: `eypi-mark.png` (192 px, `BrandLogo`), `favicon-32.png`, `favicon-48.png`, `apple-touch-icon.png` (180), `icon-192.png`, `icon-512.png` are resized from the source. To regenerate, resize the source with any lanczos resizer to those square sizes.
