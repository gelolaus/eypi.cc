# Security policy

## Reporting a vulnerability

Please report security problems privately so they can be fixed before they are public.

Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue or pull request for a vulnerability.

Include what you found, the steps to reproduce it, and what an attacker could do with it. Do not include real passwords, tokens, or other people's personal data.

## What to expect

- The maintainer will acknowledge your report as soon as they can. This is a volunteer student project, so there is no guaranteed response time.
- You will be told when it is fixed, and credited if you want to be.

## Scope

In scope: the code in this repository and the live site at eypi.cc and its API.

Out of scope: denial-of-service or load testing, social engineering, spam, and attacks on Microsoft, Cloudflare or other third-party services.

## Please do

- Test only with your own account and your own data.
- Stop and report as soon as you can see data that is not yours.
- Give the maintainer a reasonable time to fix the problem before sharing details.

## Secrets

If you find a leaked secret or key in this repository or its history, report it the same way and do not use it.
